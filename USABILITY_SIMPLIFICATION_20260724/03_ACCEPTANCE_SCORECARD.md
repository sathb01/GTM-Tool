# Usability Acceptance Scorecard

## Orientation

- [ ] The current company and current workflow are visible.
- [ ] The primary next action is visible without scrolling.
- [ ] The user can explain whether they are reading a plan, consulting an asset,
  or performing work.
- [ ] No internal system label appears as user guidance.

## This Week

- [ ] No more than three current priorities are visible.
- [ ] Every priority shows its output and completion rule.
- [ ] Every priority shows the relevant reference or says none is required.
- [ ] Status, owner, and evidence are edited in the same priority card.
- [ ] No ordinary priority requires a separate action-runner page.
- [ ] Future weeks and history do not compete with current work.
- [ ] Completed work cannot carry forward.

## Navigation

- [ ] Plan, Reference Assets, Work Tools, and Company Setup are distinct.
- [ ] Plan Status is not a redundant primary destination.
- [ ] Reference assets open separately when useful beside the plan.
- [ ] Work tools preserve a clear return to This Week.
- [ ] Intake revision is secondary and explicitly optional.
- [ ] No generic related-page or `Use this plan in` block remains.

## Visual Quality

- [ ] The first viewport has one dominant focus.
- [ ] Supporting context is compact and lower contrast.
- [ ] Buttons do not overlap text or each other.
- [ ] Long content is disclosed intentionally.
- [ ] Desktop navigation scrolls independently.
- [ ] Mobile reading order matches the task flow.
- [ ] No horizontal overflow occurs at tested viewports.

## Persistence and Trust

- [ ] Weekly status and evidence survive save, refresh, and record switching.
- [ ] The plan recalculates only when source answers actually change.
- [ ] A single freshness notice appears when a plan needs regeneration.
- [ ] Existing answers are never presented as missing.
- [ ] AI and system recommendations are distinct from user evidence.

## Release Gate

- [ ] Four synthetic company profiles render without errors.
- [ ] Two companies complete a full four-week cycle.
- [ ] Intake-to-plan and plan-to-work routes remain valid.
- [ ] Asset print, PDF, and workbook controls remain correct.
- [ ] All existing blocking release checks pass.
