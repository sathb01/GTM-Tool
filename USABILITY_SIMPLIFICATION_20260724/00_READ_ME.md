# GTM Intelligence OS Usability Simplification

Date: 2026-07-24

## Objective

Make GTM Intelligence OS feel like a guided operating system rather than a
collection of forms, reports, assets, and tools.

The redesign is organized around the user's current job:

1. Define the GTM foundation.
2. Decide what to do.
3. Execute the current week.
4. Review evidence.
5. Revise the foundation only when evidence or new information requires it.

## Files

- `01_USABILITY_SIMPLIFICATION_BRIEF.md`: current problems, target experience,
  design rules, and implementation order.
- `02_SCREEN_AND_ACTION_INVENTORY.md`: disposition of the current screens,
  assets, tools, and transitions.
- `03_ACCEPTANCE_SCORECARD.md`: release criteria for intuitive, focused,
  visually coherent workflows.
- `04_IMPLEMENTATION_STATUS.md`: what changed in this pass, what was retained,
  and the next usability opportunities to evaluate with users.

## Product Rule

Do not add a page, asset, or link simply because related information exists.
Create a separate surface only when it helps the user perform work, collect
evidence, communicate a decision, or make the next decision.
